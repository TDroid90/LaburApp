# Publicación 0.9

El identificador Android/iOS es `com.alsema.laburapp` y la versión actual es `0.9.0`. El dominio `laburapp.work` no se declara todavía como vínculo universal porque aún no está controlado por el proyecto; el esquema privado `laburapp://` queda preparado para recuperación móvil.

El despliegue web puede publicarse en Vercel. Antes de enviar a Apple o Google faltan las cuentas de tienda, credenciales EAS de producción, URLs legales definitivas, ficha y capturas de tienda, clasificación etaria, flujo visible de eliminación de cuenta y una ronda física de pruebas iOS/Android. No publicar pagos protegidos como función real mientras el proveedor de pagos siga simulado.
